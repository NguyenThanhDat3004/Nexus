# Backend Domain Modules

This directory contains the domain-driven modular monolith packages:

- `identity/`: Authentication, OAuth2/OIDC, Roles & RBAC/ABAC Policies
- `organization/`: Organization Tenants, Projects, Teams, & Workspace Membership
- `collaboration/`: Workspaces, Private Channels, Direct Messaging, Threads, Reactions
- `context/`: Requirement Tagging, Decision Tracking, Customer Confirmations, Cross-Team Bridge
- `integration/`: Jira & GitHub OAuth Sync, Webhook Verification, External References
- `search/`: Pre-retrieval Authorization Filters, Search Index Synchronization
- `notification/`: Real-time WebSocket Gateway & Mobile Push Notification Dispatcher
- `audit/`: Immutable Security Audit Logs & Break-Glass Action History
